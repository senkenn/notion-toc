# Notion ToC

Browser extension that auto-generates a Table of Contents sidebar from headings in Notion pages.

## Features

- Detects H1/H2/H3 headings and displays them in a side panel
- Click to scroll to the heading
- Auto-updates on heading edits and page navigation
- Light/dark theme support
- Toggle button to show/hide

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build        # Chrome
pnpm build:firefox # Firefox
```
